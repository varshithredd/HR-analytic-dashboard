# HR Analytics Dashboard

An HR analytics dashboard project distributed as a downloadable archive.

## Project files

[Download the project ZIP](HR%20Analytics%20Dashboard%20zip%20file.zip)

## Getting started

1. Download the ZIP file from this repository.
2. Extract it into a local folder.
3. Inspect the extracted files to identify the dashboard format, supporting data, and required application.
4. Open the dashboard in the appropriate application and update local data paths if necessary.

## Repository status

The repository currently stores the project inside a ZIP archive. The dashboard platform, measures, and runtime requirements have not been verified from the archive, so this README does not claim specific tools or business results.

To make the project easier to review, future improvements can include extracted source files, a dashboard screenshot, a data dictionary, and a short explanation of the metrics.
